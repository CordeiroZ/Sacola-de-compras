# 🛍️ Sacola de Compras

Este é um **projeto simples que criei como treino para meus estudos de JavaScript e modularização**, mas que também me ajuda no dia a dia a **organizar minhas compras de forma prática**.

---

## ✨ Funcionalidades

✅ Adicionar itens à lista de compras  
✅ Marcar itens como concluídos (riscado)  
✅ Mostrar a data e hora em que o item foi adicionado  
✅ Avisar quando a lista estiver vazia  
✅ Código modular com funções separadas para facilitar o aprendizado e manutenção

---

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (com `export/import` para prática de modularização)
